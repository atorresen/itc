Boolean Logic

George Boole (1815-1864) wanted everything to be either true or false, with nothing in between. And so, he formalized Boolean logic: a way of computing with binary truth values, i.e. true or false.

The word boolean refers to a variable that can only have two possible values: true (1) or false (0).

State Variables

State variables are booleans that keep track of the “state” of a system, e.g., whether a condition is true or false. State variables are useful tools for referencing the same condition in multiple places. Here is an example in p5.js:

// define a global variable displayQ that will be true when the rectangle is displayed and false when the rectangle is hidden
let displayQ = false;

// update the value of displayQ when the mouse is pressed using mousePressed()
function mousePressed () {
  displayQ = !displayQ; // any time the mouse is pressed, change displayQ to its opposite
}

// refer to the value of displayQ within draw()
draw() {
  if (displayQ) {
    rect(50, 50, 100, 200);
  }
}

Note: I usually add a Q to the end of my state variable names to indicate that their value is either “true” or “false” (i.e., the answer to a true or false Question)
