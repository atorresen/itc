Title

Update your webpage's title in the <head></head> of your HTML document (VS Code sets the title to "Document" by default).

<head>
  ...
  <title>Your Title Goes Here</title>
  ...
</head>

Favicon

A "favicon" is the small image that shows in the browser tab for a webpage.

To add a favicon to your webpage, choose an image and save it as an .ico file type. Add the image to your project folder. Then, add the following link to the <head></head> of your HTML document, with the appropriate file path for your icon in the href:

<head>
  ...
  <link rel="icon" href="images/icon.ico"></link>
  ...
</head>

Alt text

When you add an img to an HTML file, you should also write a brief description of the image for the alt text. This helps optimize your webpage for search engines (see SEO below), offers backup content in case images fail to load, and makes the webpage more accessible for vision-impaired users.

<img src="images/happyCow.png" alt="A photo of a cow smiling at the camera"></img>

SEO

SEO stands for Search Engine Optimization, and refers to ways of increasing the likelihood that your webpage will appear in the results for relevant searh engine (Google, Ecosia, Bing, etc.) searches. Search engines parse the HTML of webpages for key words, looking in the title, header (h1 – h6) tags and the img alt text. You can also directly provide these key words by adding a description for your page (and naming yourself as the author, while you're at it).

Add the following meta tags in the <head></head> of you HTML document, filling in your own information as necessary. It is best practice to keep the description under 105 characters:

<head>
  ...
  <meta name="description" content="Tutorial for adding title, icon, alt text, and SEO description to HTML webpages">
  <meta name="author" content="AnneMarie Torresen">   ...
</head>

Also, if you don't want your page to appear in search engine results, you can include the following in your HTML <head></head>:

<head>
  ...
  <meta name="robots" content="noindex">
  ...
</head>
